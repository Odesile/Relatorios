<h1>Sistema de gerenciamento de relatórios</h1>

<h3>❓ O que é ❓</h3>
<p>
O sistema desenvolvido em conjunto a participantes dentro do Instituto Federal de Educação, Ciência e tecnologia da Bahia (IFBA) definido como projeto de extensão.

Teve seu inicio 10 de Dezembro de 2025 e tendo una duração de 1 ano (365 dias), sendo assim, sua finalização prevista para 10 de Dezembro de 2026. O projeto teve sua duração uniformemente divido entre 10 Capsulas,
Sendo este repositório a Capsula de numero 1.
</p>



<h3>🎯 Finalidade 🎯</h3>
O sistema surge com a finalidade de suprir a necessidade de gerenciamento de relatórios, garantindo assim um controle de fluxo mais organizado dentro das precisões empresariais.



<h3>✏️ Metodologia ✏️</h3>
<h4>Dentro do desenvolvimento do projeto foram-se ultilizadas as linguagens para o desenvolvimento do Front-end:</h4>
HTML5, CSS3 e Javascript

<h4>Para o desenvolvimento do Back-end:</h4>
MySQL, Javascript e arquivos .env

<h4>Além das linguagens, usou-se também padrões de projetos necessários como:</h4>
MVC (Model View Controller):
  <h6><b>Model</b>: Responsável pelos dados, tratamentos e regras de negócio<br>
      <b>View</b>: Responsável pela interface do usuário<br>
      <b>Controller: Intermédio entre interface e lógica </b>:
  </h6>
DAO (Data Acess Object)
  <h6>
    <b>DAO:</b> Responsável pelas operações de Leitura, Escrita, Atualização e Remoção (CRUD) dentro do banco de dados, ou seja, separa a regra de negócios da lógica do acesso ao banco de dados
  </h6>
